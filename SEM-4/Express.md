# **Express**



Express is a minimal and flexible web framework for node.js, it is used to build web servers and APIs. It simplifies backend development by providing utilities for -

* Routing
* Middleware
* Request - Response handling
* API development



The app object represent the complete express application it is used to define routes use middlewares and configure server setting
